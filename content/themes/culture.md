# 主題3：談論文化差異 — Cultural Differences

## 核心詞彙語庫

### 描述文化特質
| 英文 | 中文說明 |
|------|---------|
| It's a cultural thing. | 這是文化上的差異 |
| Back where I'm from... | 在我家鄉… |
| That's pretty common here. | 這在這裡很普遍 |
| We tend to... | 我們通常傾向於… |
| It varies a lot by region. | 因地區差異很大 |

### 表達好奇與尊重
| 英文 | 中文說明 |
|------|---------|
| That's really interesting. | 這真的很有趣 |
| I didn't know that. | 我不知道這一點 |
| How do you feel about that? | 你對此有什麼感受？ |
| Is that a recent change or has it always been that way? | 這是最近才有的變化，還是一直如此？ |
| I can see how that would make sense. | 我能理解為什麼這樣做有道理 |

### 比較文化
| 英文 | 中文說明 |
|------|---------|
| In contrast... | 相比之下… |
| That's quite different from... | 這和…很不一樣 |
| We have something similar, but... | 我們有類似的東西，但… |
| I think both approaches have merit. | 我認為兩種方式都有道理 |
| Neither is right or wrong — just different. | 沒有對錯之分，只是不同 |

### 談工作文化差異

## Turn Dialog 範例

### 6-Turn（台灣與外國文化對話）
```
A: I heard people in Taiwan work really long hours. Is that true?
B: Yeah, overtime culture is pretty embedded here. It's changing slowly, though.
A: What do you think drives it?
B: I think it's partly historical — the economic boom era, when hard work meant survival.
A: That makes sense. And now it's just... habit?
B: Exactly. Old habits die hard. But younger generations are pushing back more.
```
