# 主題1：安慰朋友 — Comforting a Friend

## 核心詞彙語庫

### 表達同理心
| 英文 | 中文說明 |
|------|---------|
| I'm sorry to hear that. | 很遺憾聽到這件事 |
| That must be really tough. | 那一定很難熬 |
| I can imagine how you feel. | 我能想像你的感受 |
| It's completely understandable. | 完全可以理解 |
| You have every right to feel that way. | 你有權利有這種感受 |

### 主動傾聽
| 英文 | 中文說明 |
|------|---------|
| What's going on? | 發生什麼事了？ |
| Do you want to talk about it? | 你想聊聊嗎？ |
| I'm all ears. | 我在聽，你說吧 |
| Take your time. | 慢慢來，不用急 |
| Go on, I'm listening. | 繼續說，我在聽 |

### 提供支持
| 英文 | 中文說明 |
|------|---------|
| I'm here for you. | 我在這裡支持你 |
| You don't have to go through this alone. | 你不用一個人扛 |
| I've got your back. | 我挺你 |
| Whatever you need, just say the word. | 你需要什麼，說一聲就好 |
| We'll figure this out together. | 我們一起想辦法 |

### 正向引導
| 英文 | 中文說明 |
|------|---------|
| Things will get better. | 事情會好轉的 |
| It's just a rough patch. | 只是一段低潮期 |
| You're stronger than you think. | 你比你想的更堅強 |
| Give it some time. | 給它一點時間 |
| Every setback is a setup for a comeback. | 每次挫折都是反彈的準備 |

## Turn Dialog 範例

### 2-Turn（入門）
```
A: I've been feeling really low lately.
B: I'm sorry. Do you want to talk about it?
```

### 4-Turn（進階）
```
A: I think I'm burning out. I'm just exhausted all the time.
B: That sounds really draining. Have you had any time to recharge?
A: Not really. I feel guilty taking breaks.
B: I hear you. But you can't pour from an empty cup.
```

### 6-Turn（挑戰）
```
A: I broke up with my partner last week.
B: Oh no, I'm really sorry. Are you okay?
A: Honestly? Not really. I keep second-guessing myself.
B: That's totally normal. Breakups are hard, especially when you're the one who initiated it.
A: Yeah. I just don't want to have made a mistake.
B: You made the best decision you could with what you knew at the time. That's all anyone can do.
```

## 高頻句型練習

**情境**：你的朋友剛失去工作

嘗試用以上詞彙，不看提示，說出一段 4-Turn 安慰對話。錄音並回聽。
