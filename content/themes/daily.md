# 主題6：日常生活小事 — Everyday Life

## 核心詞彙語庫

### 開啟閒聊
| 英文 | 中文說明 |
|------|---------|
| What have you been up to? | 你最近在幹嘛？ |
| Anything new with you? | 你有什麼新鮮事嗎？ |
| How's everything going? | 一切還好嗎？ |
| Long time no see! | 好久不見！ |
| You look great! | 你看起來氣色很好！ |

### 談天氣
| 英文 | 中文說明 |
|------|---------|
| It's been so hot lately. | 最近真的好熱 |
| I can't stand this humidity. | 我受不了這個濕度 |
| Looks like it's going to rain. | 看起來要下雨了 |
| What a beautiful day! | 今天天氣真好！ |
| The weather's been all over the place. | 天氣一直很不穩定 |

### 食物與餐廳
| 英文 | 中文說明 |
|------|---------|
| I'm starving. | 我餓死了 |
| I've been craving... | 我最近很想吃… |
| Let's grab a bite. | 我們去吃點東西吧 |
| That was absolutely delicious. | 那真的超好吃 |
| I'm stuffed. | 我撐死了 |

### 休閒娛樂
| 英文 | 中文說明 |
|------|---------|
| I've been binge-watching... | 我最近在追看… |
| Have you seen...? | 你有看過…嗎？ |
| I'm into... lately. | 我最近迷上了… |
| I need a break. | 我需要休息一下 |
| Let's hang out sometime. | 找時間一起出來玩 |

### 自然轉場句
| 英文 | 中文說明 |
|------|---------|
| Anyway... | 話說回來… |
| Speaking of which... | 說到這個… |
| Oh, by the way... | 對了，順帶一提… |
| That reminds me... | 這讓我想到… |
| Before I forget... | 趁我還沒忘… |

## Turn Dialog 範例

### 4-Turn（週末閒聊）
```
A: How was your weekend?
B: Pretty relaxing, actually. I just stayed in and watched movies.
A: Yeah? Anything good?
B: I rewatched Interstellar. Still holds up. Blew my mind again.
```

### 6-Turn（聊食物）
```
A: I've been craving hotpot all week.
B: Oh man, same. It's been so cold lately.
A: Right? Perfect hotpot weather.
B: Have you tried that new place on Zhongxiao East Road?
A: Not yet. Is it good?
B: Incredible. The broth alone is worth the trip.
```
