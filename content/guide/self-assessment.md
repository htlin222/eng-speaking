# Self-Assessment Rubric

錄完音之後，用這個量表評估自己。不是給別人打分，是給自己一個誠實的鏡子。

---

## 四個維度

### 1. Fluency — 流暢度

| 分數 | 描述 |
|------|------|
| 3 | 句子之間自然銜接，停頓落在思考點而非找詞點 |
| 2 | 偶爾卡頓，但能繼續推進，不崩潰 |
| 1 | 停頓頻繁，句子切碎，聽起來像在翻譯 |

### 2. Rhythm — 節奏感

| 分數 | 描述 |
|------|------|
| 3 | 重音與弱音有對比，句子有起伏，不像機器人 |
| 2 | 節奏基本正確，但偶爾平板 |
| 1 | 每個字力道相同，像在讀單字表 |

### 3. Language — 用語

| 分數 | 描述 |
|------|------|
| 3 | 使用當天的目標句型，且融入得自然 |
| 2 | 使用了部分句型，但有些地方退回到更簡單的說法 |
| 1 | 幾乎沒有用到當天句型，還是用最基礎的表達 |

### 4. No Chinese Switch — 不切換中文

| 分數 | 描述 |
|------|------|
| 3 | 全程英文，就算說錯也用英文修正 |
| 2 | 一、兩次切換中文，但馬上拉回來 |
| 1 | 多次切換，或說不下去就停住 |

---

## 計分

| 總分 | 意義 |
|------|------|
| 10–12 | 這一天的目標達成，可以繼續 |
| 7–9 | 接近，再練一次再錄 |
| 4–6 | 回去聽示範對話，再嘗試 |
| 3 | 今天的內容超出舒適圈太多，這是好事，明天繼續 |

---

## 注意

分數低不代表你差。代表你找到了還沒建好的部分。那才是練習的意義。
